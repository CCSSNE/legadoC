## 更新记录

### 2026-08-14

**整页书签（页面书签）**

- 新增下拉添加 / 删除整页书签（翻页模式）：在页面顶部从屏幕往下拉，页面跟手下移，右上角从页顶"长"出一枚拟真小标签（可见高度=下拉距离 1:1，长满 64dp 后标签固定、页面继续下滑）；松手超过阈值即添加 / 删除，回弹期间标签保持满尺寸留在右上角。删除模式回弹期间标签消失。
- 新增"下拉添加整页书签"开关（默认开）与"整页书签颜色"设置（全局生效）；标签绘制始终先于正文裁剪，常驻 / 下拉标签都能完整显示。
- 新增"整页书签尖角样式"设置：尖角朝下、尖角朝上（底部凹口）两种，默认保持尖角朝下；翻页模式、滚动模式与下拉动效同步生效。
- 整页书签按页首文字匹配（公共前缀占比 ≥ 80%）显示，文字变更后依然能对上。
- 书签表新增 `isPageBookmark` 字段，DB 升级至 99。
- 整页书签与普通书签彻底分开：阅读页单击不劫持、不弹备注气泡、不弹编辑；目录书签列表 / 网格带"整页"标记，只展示位置与页面文字，不展示备注与样式效果；多选批量编辑不受限。

**跨页复制**

- 选中文本后把手指移到最右下角并停留片刻（500ms），自动翻到下一页并把选区延续到新页页首继续选择；持续停在角落会持续跨页，可跨章。触发区域为右下角物理正方形，边长=屏幕长边 1/8（竖屏约纵向 1/8 × 横向 1/4，横屏自动反转）。
- 新增"跨页复制"开关（默认开）。

**选区手柄与颜色**

- 新增"选区手柄样式"：圆球加杆 / 仅圆球 / 无手柄三选，默认球+杆；无手柄时不可拖动调整选区。
- 新增"选区颜色"（选中文字背景色，支持透明度）、"选区手柄颜色"（球+杆整体上色，支持透明度）。
- 修复选区手柄"球/杆乱飞"：手柄锚点从"图右/左边缘"改为"球杆中线"，拖动映射改为"手指按在球上→杆尖跟随"，球始终跟手、杆尖对准选区边界，反向拖动与跨页复制不受影响。

**选区放大镜**

- 新增"选区放大镜"开关（默认开）：拖动选区手柄时，放大镜镜头跟随手指放大附近文字（自研 View 替代系统 Magnifier，支持自定义样式）。

**书签交互**

- 选中文本弹窗里的书签 / 段落书签恒定为"添加"（去掉命中旧书签即变编辑）。
- 目录书签页打开时自动定位：优先把当前页面内第一条书签顶到列表首位，当前页没有则退到当前章节第一条，章节也没有才取章节距离最近的一条；列表 / 网格均生效。
- 单击普通书签除切换备注气泡外，额外弹出临时"编辑当前标签"悬浮窗（重叠命中规则：文本更短优先、相同创建更晚优先；点其他区域消失，约 1 秒无操作自动关闭）。
- 备注气泡新增"边框"与"箭头"两组设置：各自可设置是否显示、颜色、透明度（默认边框显示、透明度 80%）。

**EPUB**

- 修复经典模式下原生 EPUB 布局生成空页时页面空白：回退到同一章节的 HTML 内容排版，兼容本应用导出的缺失封面资源 EPUB。

**阅读**

- 点击区域新增"强制打开主菜单"动作：听书 / 自动翻页 / 全文搜索时也能直接打开阅读主菜单。

**修复**

- 修复多个设置项默认值前后端不一致（界面显示开关与实际行为相反）：
  - 朗读时音量键翻页：默认改为关闭（原界面显示关、实际仍翻页）。
  - 启动时检查更新：默认改为开启（原界面显示开、实际不检查）。
  - 封面设置页"显示作者"开关可用性判断对齐默认值。
  - 朗读跟随系统语速：默认改为关闭；隐藏悬浮窗默认改为开启；朗读默认语速由 5 调整为 30。

### 2026-08-13

**App 自动更新**

- 新增更新设置：每次启动自动检查（默认开启）、接收 Pre 版本推送（默认关闭）、下载加速源（默认 ghfast.top，可选直连 / ghproxy / gh-proxy / 自定义地址）。
- 新增"立即检查更新"按钮；切换"每次启动检测"开关即时触发一次检查。
- 检查 GitHub Release 新版本：按 versionCode 取最高版本（从 APK 文件名解析，不再被 tag 里的日期数字误判），弹出更新说明，下载完成自动唤起系统安装。

**导出与导入**

- 导出 TXT 拆分出独立选项"导出 TXT (zip)"：本地 TXT 正文原样打包（不加书名头/缩进、不改写章节），图片/视频/音频与书签、替换规则作为外挂数据写入压缩包，重新导入可完整还原且不章节错乱；原"导出 TXT"保持原样行为。
- TXT(zip) 导出新增"导出书签"选项：书签随 `bookmarks.json` 进压缩包，导入时同步还原。
- TXT(zip) 导出新增"替换净化"外挂：开启后把当前书生效的替换规则写入 `replace_rules.json`（正文保持原文），导入时同步还原规则并自动打开该书的净化开关。
- EPUB 导出修复：配图媒体原文件此前导出为 0 字节（LazyResource 文件名传错），修复后图片/视频/音频完整打包；新增书签侧车（`legado_bookmarks.json`），导入时还原书签与配图。
- PDF 导出新增书签：压缩包内含 `bookmarks.json`，导入时同步还原。
- 压缩包导入失败时给出明确错误提示；默认导出图片改为开启。
- 修复压缩包导入：VIEW 打开 zip 走统一导入流程（解压保存到书籍目录 + 还原配图/媒体/书签）。

**书架**

- 书架"全部"分组支持在分组管理中关闭，关闭后真正不再显示；仅当用户未关闭且其他分组都为空时才兜底显示，避免空白。

**修复**

- 修复配图还原位置：全书插图按段落指纹匹配，不再依赖章节索引；段间锚点未匹配时不再堆到章末。
- 修复压缩包导入失败：书籍保存目录未设置时兜底保存到应用外部目录，不再抛 NoBooksDirException。

### 2026-08-12

**备份与恢复**

- 备份新增阅读记录头像目录，恢复后自动把头像配置里的绝对路径修正到当前应用目录，从 R 版换到 C 版恢复也能显示自定义头像。
- 自定义封面备份增强：书架和分组里指向本地图片的自定义封面，备份时会一并并入封面目录，恢复后按文件名自动映射路径；恢复时找不到对应封面文件时保留原路径，不再清空。

**配图（图片 / 视频 / 音频）**

- 长按菜单入口正式改名"插入"：对话框内提示"选择图片、视频或者音频"，可插入图片、视频或音频。
- 插入位置改为任意文本选区：只选一段 → 插在该段之后；跨多段（如 1/2/3 段）→ 仍插在第一段与第二段之间。
- 配图扩展为图片、视频、音频三类媒体：选择器放开为 `*/*`，可一次多选图片/视频/音频，保存前拦截非媒体文件并提示。
- 插入时按“文件名扩展名 → MIME → 文件头”三级识别媒体类型，并修复保存时无点号扩展名被默认当成 jpg 的根因，视频/音频不再被误存成图片。
- 新增独立音频块：阅读页内联播放，支持播放/暂停、进度条点击与拖动 seek（触摸优先级最高），翻页继续播放、退出阅读页停止，多个音频实例的播放/暂停状态同步刷新。
- 新增“配图音频播放时音量键调音量”开关（阅读设置）：内嵌音频块播放时音量键不再翻页，改为调节音量。
- 新增视频全屏播放：多视频可左右滑动、滑走即停止；单个视频禁止滑动并自动横屏；视频自动抽帧作为封面并显示时长。
- 配图目录页：图片显示缩略图，视频显示抽帧+时长，音频显示音符图标+时长；顶部改为小按钮行，新增多选/全选，多选模式点击勾选，长按支持保存 / 保存所有 / 删除所选。
- 全屏查看体验：图片单击返回阅读页，全屏黑色背景，修复缩放卡顿与手势冲突。
- 配图布局改为单图 / 双图 / 一行三张 / 一行四张，并新增两行两列四宫格；阅读排版与 PDF 导出同步支持。
- TXT / EPUB / PDF 导出均支持媒体再导入：TXT 用压缩包导出并在导入时还原，EPUB 嵌入配图标记与侧车清单、导入自动重写图片源，PDF 用压缩包+归一化坐标导出、再导入裁切还原并恢复阅读页热区；配图备份恢复同步覆盖。
- 修复配图设置对话框崩溃、文本菜单配图项闪现（按选区状态重建、弹窗原地更新、重新弹出前清理残留）等问题。
