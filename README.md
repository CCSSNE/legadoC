**高亮规则（新功能）**

- 新增高亮规则：按正则命中的正文文字在排版层自动应用显示效果。效果体系与书签一致（单/双/波浪下划线、高亮、文字变色、删除线，可组合、逐效果独立设色），仅作显示、不影响书签；作用范围与替换规则一致（scope / excludeScope 书名或书籍 URL，全局生效）；多规则命中效果叠加，按排序先到先得。数据库升级至 113（新增 `highlight_rules` 表）。

- 修复新建高亮规则对话框闪退自关导致「+」无反应；预置数据补齐于 `DefaultData`，与既有默认规则互不重复导入。
