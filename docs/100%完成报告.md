### 🔧 工作原理

#### 音频书播放流程
```
1. 用户点击朗读按钮
2. ReadAloud.play() 启动 UnifiedReadAloudService
3. UnifiedReadAloudService 创建 SourceAudioEngine
4. SourceAudioEngine 使用 ExoPlayer 播放音频
5. 引擎回调更新进度 → EventBus → ReadAloudDialog
6. 用户在对话框看到实时时间进度（00:00 / 15:30）
```

#### 普通书朗读流程
```
1. 用户点击朗读按钮
2. ReadAloud.play() 启动 UnifiedReadAloudService
3. UnifiedReadAloudService 创建 SystemTtsEngine
4. SystemTtsEngine 使用 TextToSpeech 朗读
5. 引擎回调更新进度 → EventBus → ReadAloudDialog
6. 用户在对话框看到段落进度（段 3 / 15）
```
