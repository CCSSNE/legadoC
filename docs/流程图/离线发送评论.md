# 离线发送评论

## 功能目标
- 缓存评论后，离线时仍可发表段评/章评，先记录；
- 离线评论只能通过‘发送离线评论’手动触发发送，或者导出 JSON；不存在网络恢复自动发送。
- **开关控制发送策略，不代表真实网络状态。**
  - 开：无论真实有没有网，都拦截并记录。
  - 关：不拦截，走原书源正常发送流程；如果真实没网，就让原流程正常失败。
- 离线评论可导出 JSON，供手动处理

## 阅读界面菜单
阅读界面右上角“更多”中增加：

### 1. 离线评论模式
- 开关。
- 开启后，自动拦截发送的评论，**拦截并记录，不立即发送**。(无论有没有网络)

### 2. 导出离线评论
- 导出全部离线评论，不限当前开启期间。
- JSON文件记录评论类型（段评/章评）、书籍、章节、段落位置（段评）、评论内容、发送状态。
- 已发送评论继续保留，并标记“已发送”。

### 3. 清除离线评论
- 清除全部主动记录的离线评论。包括待发送、失败、已发送的全部历史记录。
- 点击后必须二次确认。

### 4. 发送离线评论
- 发送当前未发送评论，还有之前发送失败的评论。

- 开始发送后，自动关闭“离线评论模式”。

- 已发送项更新状态；任一失败直接报错。

  不存在自动发送评论，一定要.1下这个发送离线评论，手动的触发发送所有评论功能。
