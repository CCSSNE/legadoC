# 测试原则（强制）

> 本文件为项目测试的强制约束，所有涉及本项目的功能测试、回归测试、崩溃验证都必须遵守。

## 一、只能用模拟器测试

1. 所有测试必须使用**模拟器**（Android 模拟器），禁止使用真机测试。
2. 禁止通过 adb 向任何已连接的真机推送、安装任何 APK 或应用。
3. 禁止通过 adb 操控已连接的实体手机的任何功能（点击、截图、输入、安装、卸载等）。
4. 在执行任何 adb 命令前，必须先确认目标设备是模拟器；如果设备列表中出现实体机，禁止对其执行安装/操控命令。

## 二、模拟器来源

1. 本机固定使用**雷电模拟器（LDPlayer）**，路径：
   `F:\leidian\LDPlayer14\dnplayer.exe`
2. 如果雷电模拟器没有启动，按以下顺序处理：
   - 先自行尝试启动：`F:\leidian\LDPlayer14\dnplayer.exe`
   - 启动失败或需要用户协助时，请用户手动打开雷电模拟器。
3. 只有雷电模拟器可用时才进行安装与测试；模拟器未就绪时，不得退而求其次在真机上测试。

## 三、测试流程要求

1. 每次代码改动后：重新编译 → 安装到**雷电模拟器** → 在模拟器中复现/验证。
2. 安装命令必须限定模拟器序列号（如 `-s emulator-5554` 或雷电的 `127.0.0.1:5555`），不允许裸 `adb install` 命中未知设备。
3. 测试过程中遇到崩溃：先收集崩溃日志 → 定位代码问题 → 修复 → 重新编译 → 再到模拟器上回归验证。

## 四、违规后果

任何在真机上的安装、推送或操控行为都属于严重违规，必须在测试前、测试中持续自查目标设备身份。
