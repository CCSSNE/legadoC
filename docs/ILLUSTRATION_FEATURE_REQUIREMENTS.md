# 配图（插图）功能需求确认稿 v1.0

> 状态：已与用户逐条确认（2026-08-12）。本文档为后续实现、验收的唯一需求依据。
> 配套代码事实：本仓库（legadoC）排版引擎已有 `ImageColumn` + `TextLine.isImage`，支持正文嵌图、点击、长按回调；全屏看图有 `PhotoView`（双指缩放）+ `PhotoDialog`；导出目前仅 TXT/EPUB，无 PDF 写出能力；PDF 阅读为整页位图渲染（`PdfFile`，一章 = 10 页），不解析文本。

## 一、需求总览（原始需求 0-6）

0. 增加"配图"功能。仅当用户选区跨越两段时，在长按小悬浮窗中增加"配图"选项，可在两段之间插入图片。
1. 导入配图时可设置图片显示高度，宽度按原始比例自动计算；宽度达到页面上限时，高度同步限制在可容纳范围内。支持单图、双图及多图布局，并按相同规则自动限制尺寸。
1.1 提供独立的"独占一页"选项。开启后配图单独占用一个页面；未开启时配图默认插入所选两段正文之间。
2. 阅读时点击配图可进入全屏查看，全屏支持双指放大、缩小；长按图片时从底部弹出操作菜单，支持将当前图片保存至相册。
3. 增加配图后，导出书籍时支持选择 TXT、EPUB 或 PDF。本应用导出的 EPUB、PDF 再次导入时应完整兼容配图功能。
4. 书内目录界面在"目录""书签"之外增加"配图"选项，集中展示全书所有配图，并支持快速跳转到对应正文位置。
5. 配图列表支持列表和宫格两种展示方式。列表模式按行展示：右侧显示配图缩略图，左侧显示该配图前后两段正文内容。宫格模式可选择二宫格、三宫格等布局，以图片展示为主，文本仅显示章节及章节名称；空间不足时章节名称可省略或截断显示。
6. 配图功能首期主要支持 TXT。EPUB、PDF 中能够扫描并准确定位的配图也可兼容；无法扫描、定位或涉及现有不支持特性的内容不处理。

## 二、已确认的决策（逐条问答结论）

1. PDF 再导入兼容程度：**完全恢复**（针对本应用自导出的 PDF）。
2. TXT 导出带配图方式：**导出压缩包**，内含 TXT + 配图 + 配图数据 JSON。**不改动原 TXT 文本，不在文本中插入任何标记**；配图数据全部放 JSON。
3. EPUB/PDF 标记：**可以加入专用标记和版本信息，只要不可见（不影响用户正常阅读）**。
4. 锚点容错：记录**前后段落文本指纹**；原文变化后按指纹重定位，找不到则**放到该章末尾**。
5. "跨两段"触发：**必须恰好选中两段**（A 段一部分 + B 段一部分）。选中三段及以上，不出现配图选项。
6. 章末插入：因无法跨章选择，**单独选中某章最后一段文本时也出现配图选项，配图插入该章末尾**。
7. 三段及以上：**不出现配图选项**。
8. 多图排版：**固定布局**（如双图、三图、四宫格），不做完全自动排版。
9. 配图原始文件：**纳入书籍备份、恢复和迁移**，保证换设备或恢复数据后配图不丢失。

## 三、最终功能规则

### 3.1 触发与插入位置

- 恰好跨两段（A 段一部分 + B 段一部分）→ 长按小悬浮窗出现"配图"选项，图片插入 A/B 两段边界。
- 选中某章最后一段（单段）→ 出现"配图"选项，图片插入该章末尾。
- 选中三段及以上 → 不出现"配图"选项。
- 选区受现有引擎限制（当前页 / 当前跨页内、不可跨章）：章首插入、跨页段间插入，v1 不提供入口。

### 3.2 图片导入、尺寸与布局

- 布局为固定枚举：单图、双图、三图、四宫格。
- 单图：用户设置显示高度，宽度按原始比例自动计算；宽度达到页面上限时，高度同步限制在可容纳范围内。
- 多图：宫格等分可用宽度，行内图片等高；按同一尺寸规则自动限制。
- "独占一页"开关：开启后配图单独占一页；关闭后默认插入所选两段正文之间。

### 3.3 阅读交互

- 点击配图 → 全屏查看（复用 PhotoDialog/PhotoView，支持双指缩放）。
- 长按配图 → 底部弹出操作菜单，支持将当前图片保存至相册。
- 复用现有 `ImageColumn` 的点击/长按回调链路（`onImageLongPress`、`clickImgWay`）。

### 3.4 目录页"配图"页签

- 在 `TocActivity` 的"目录""书签"之外增加"配图"页签。
- 集中展示全书所有配图，点击跳转到对应正文位置。
- 列表模式：按行展示，右侧配图缩略图，左侧该配图前后两段正文内容。
- 宫格模式：可选二宫格、三宫格等布局，以图片为主，文本仅显示章节及章节名称；空间不足时章节名称省略或截断。

### 3.5 锚点与容错

- 每条配图记录：章节（index/url）+ 段落边界 + 前后段落文本指纹。
- 指纹优先：章节被目录规则、反转目录、拆分长章重新划分，或正文被替换规则/重新下载改变后，按指纹重定位。
- 指纹无法匹配时：配图放入该章末尾；必要时提示用户检查。

### 3.6 存储与备份

- 配图原始文件保存到每本书的独立目录（建议 `books/{bookDir}/illustrations/`）。
- 纳入书架备份、恢复与迁移，保证换设备/恢复数据后配图不丢失。

## 四、导出与再导入契约

### 4.1 TXT

- 导出：压缩包 = `book.txt` + `images/`（配图原始文件）+ `illustrations.json`（配图数据）。
- 原 TXT 文本一字不改，不插入任何标记。
- 再导入：走现有压缩包导入路径，检测 `illustrations.json` 并还原配图记录；不含该 JSON 的普通压缩包按原逻辑处理。

### 4.2 PDF

- 导出：压缩包 = `book.pdf` + `illustrations.json`。
- PDF 内配图按排版规则绘制在页面流中（含独占一页）。
- `illustrations.json` 记录每张配图：PDF 页码 + 页面坐标矩形 + 章节/锚点/前后段指纹/布局参数。
- 再导入（本应用自导出 PDF）：
  - PDF 仍按现有整页位图方式阅读（一章 = 10 页），不做文本解析。
  - 读取 JSON 重建配图记录；配图展示图从 PDF 页对应坐标区域裁切生成。
  - 阅读时在 PDF 页面叠加不可见点击热区，点击可全屏查看。
  - "跳转到对应正文位置" = 跳转到配图所在 PDF 页。
  - **明确不做：PDF 再导入后的段落级重排/精确段间还原**（受 PDF 位图阅读架构限制，已与用户确认）。
- 备注：压缩包不含原图时，再导入配图清晰度等于 PDF 渲染精度；如需原图级清晰度，后续在包内增加 `images/` 目录并由 JSON 引用路径（向后兼容）。

### 4.3 EPUB

- 导出：配图以**不可见**自定义标记写入（img 自定义属性 + OPF 版本元数据）。
- 再导入：识别标记还原配图记录；标记对用户不可见，不影响正常阅读。
- 实现注意：正文替换规则、HTML 清洗链路（`ContentProcessor`/`ExportImageSanitizer`）不得剥掉自定义属性，需做保护。
- 版本契约参照现有 `READABLE_CONTENT_VERSION_FLAG` 机制，带版本号以便后续演进。

## 五、数据模型建议（实现参考）

新增表 `book_illustrations`（Room v95 → v96，需 migration + schema 导出）：

- `id`（主键）
- `bookUrl`
- `chapterIndex`、`chapterUrl`（可为空）
- `anchorType`：`between_paragraphs` / `chapter_end`
- `anchorPos`：段落边界位置
- `frontFingerprint`、`backFingerprint`：前后段落文本指纹
- `imagePaths`：多图时图片路径列表（JSON）
- `layoutType`：single / double / triple / quad
- `displayHeight`：显示高度
- `pageBreak`：是否独占一页
- `sortOrder`
- `pdfPage`、`pdfRect`：PDF 再导入专属（可为空）
- `createdAt`

图片文件目录：`books/{bookDir}/illustrations/`。

## 七、明确不做（v1 范围外）

- 章首插图入口。
- 跨页 / 跨章选择的配图插入。
- PDF 再导入后的段落级重排。
- 非本应用导出的 PDF/EPUB 配图识别：仅尽力而为，不保证定位与还原。

## 八、排期建议

- 第一期：TXT 配图（插入 / 渲染 / 全屏查看 / 保存相册 / 目录"配图"tab / TXT 压缩包导出与再导入）。
- 第二期：EPUB 不可见标记契约 + 导出与再导入。
- 第三期：PDF 写出子系统（含 CJK 字体）+ 压缩包导出 + 再导入热区。

## 九、实现状态（2026-08-12 全部完成并编译通过）

### 已完成

- 数据层：`book_illustrations` 表（Room v95 → v96），字段含锚点类型/段落偏移/前后段文本与指纹/图片源列表/布局/显示高度/独占一页/PDF 页码与归一化坐标。
- 插入入口：长按小悬浮窗新增"配图"项；恰好两段（A 段一部分 + B 段一部分）插入段间，单段选中章末段落插入章末，三段及以上不显示。
- 配图设置对话框：系统多图选择、显示高度、单图/双图/三图/四宫格布局、独占一页开关。
- 排版渲染：TXT 章节按段落边界注入配图行（指纹优先匹配，锚点偏移兜底；未匹配放章末），宫格等分宽度、行内等高、宽度/高度上限自动收缩，独占一页强制分页。
- 阅读交互：点击配图全屏查看（双指缩放复用 PhotoView），长按弹出底部菜单（保存到相册 / 删除配图）。
- 目录页"配图"tab：列表（左前后两段正文、右缩略图）与宫格（二/三宫格）切换，点击跳转对应位置（章末配图跳章末页）。
- TXT 导出：带配图时导出压缩包（book.txt + images/ + illustrations.json），原 TXT 文本不改动；再导入自动还原。
- EPUB 导出/再导入：正文段间注入 `<img>`（标准阅读器可见），配图原图以确定性 md5 路径嵌入 EPUB，另附不可见侧车清单 `legado_illustrations.json`；再导入时读取侧车、裁切还原图片、重写内容图片源为配图键并重建记录。
- PDF 导出/再导入：`android.graphics.pdf.PdfDocument` 分页排版（A4、CJK 系统字体），配图按排版规则绘制并记录 PDF 页码与归一化坐标；带配图时导出压缩包（book.pdf + illustrations.json）；再导入时按坐标从 PDF 页裁切出配图原图，阅读页叠加不可见热区（点击全屏、长按菜单）。
- 备份/恢复：配图记录随 `bookIllustration.json` 备份恢复，图片目录 `illustrations/` 纳入备份压缩包与恢复。
- 构建修复：KSP 增量在跨盘符环境下报错，已在 `gradle.properties` 关闭 KSP/Kotlin 增量。

### 已知边界（首期可接受）

- EPUB 再导入后"独占一页"仅保留数据，可读模式下按行流排版不强制分页。
- PDF 再导入后正文仍按整页位图阅读（不做段落级重排），配图定位到 PDF 页；点击/长按按热区命中。
- 章节被目录规则/反转/拆分重新划分后，配图靠指纹在同一章内重定位；跨章节索引漂移不保证。
- 非本应用导出的 EPUB/PDF 不识别配图标记，按普通图片阅读。
