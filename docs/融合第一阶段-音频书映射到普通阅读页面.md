# 融合第一阶段：音频书映射到普通阅读页面

## 目标

音频书默认进入普通阅读页面，不再按书籍类型进入原来的听书页面。原听书页面保留，但从默认阅读入口中退出。

## 实现任务

1. **文字适配**：把音频书提供的文字或字幕适配为普通阅读页面可排版、翻页和定位的正文
2. **音频解构**：把书源自带音频从"音频书专属逻辑"中解构出来，作为一种听书引擎来源；它与系统 TTS、HTTP TTS 平级
3. **文字与音频映射**：把书源已有的文字和音频对应关系接入普通阅读页面已有的双击听书、指哪读哪能力
4. **进度条**：在普通阅读页面的听书菜单中增加进度条
   - 使用书源音频引擎时，显示真实音频时间，并与句子或字幕对齐
   - 使用普通 TTS 引擎时，显示章节段落进度；拖动位置映射到章节内对应段落并继续朗读
