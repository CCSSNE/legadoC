# 配图扩展：配视频 / 配音频 改动总表

> 本文档是"配图"功能扩展为"图片 + 视频 + 音频"的**唯一持久约定**，所有讨论结论都归档到这里，防止遗忘。
> 入口与说法不变：仍然叫"配图"，不加新按钮、不加新说法；只是选择媒体时图片、视频、音频都能选。

## 一、已拍板规则

1. **入口**：长按跨两段/章末段的"配图"入口不变；选择器扩展为图片 + 视频 + 音频。
2. **阅读页格子**：
   - 图片：原样显示。
   - 视频：缩略图（抽帧）+ 半透明播放键，不自动播放。
   - 音频：占位图标（音符）+ 播放键；**音频不参与任何宫格，永远单独成格**。
3. **宫格规则**：图片/视频按所选布局（双图/一行三张/一行四张/四宫格）成宫格；音频单独一格。
4. **音频位置**：按选择顺序排，具体规则见第二章。
5. **点击行为**：
   - 图片 → 全屏看图（现有）。
   - 视频 → 全屏播放（播放器 + 进度条）。
   - 音频 → **不放大**，点击直接播放（带进度条）。
6. **长按菜单**：与配图一致（保存/删除，多图有保存所有）；视频"保存到相册"存影片，音频存音乐。
7. **导出**：
   - TXT：压缩包，媒体文件 + JSON。
   - EPUB：内嵌媒体（EPUB3 video/audio）。
   - PDF：PDF 本身不能嵌视频/音频，页面上画静态首帧图，媒体文件仍打进压缩包 + JSON，再导入恢复可播放；**全部媒体都支持导出**。
8. **备份/恢复**：媒体文件与图片一样放 `illustrations` 目录，随书备份、恢复、迁移。

## 二、宫格与音频排布规则

**规则**：按选择顺序处理；图片/视频按所选布局填充宫格块；音频永远单独成格。音频与宫格块的相对顺序按"块内首元素的选择位置"排序；若音频的选择位置落在某个宫格块区间内，排在该宫格块**之后**。

示例（均选"双图"）：

| 选择顺序 | 结果 |
| --- | --- |
| 视频、音频、图片 | `[视频,图片]` 双图宫格，音频排后 |
| 音频、视频、图片 | 音频排前，`[视频,图片]` 双图宫格 |
| 视频、图片、音频 | `[视频,图片]` 双图宫格，音频排后 |
| 纯音频 × 2 | 两个独立音频格，按选择顺序排 |

## 三、待确认小点（带建议）

1. **音频点击播放的 UI 位置**：建议阅读页底部弹出紧凑播放条（播放/暂停 + 进度条 + 时长 + 关闭），不占全屏、不内嵌进画布。待确认。
2. **播放中翻页/退出阅读**：建议翻页或退出阅读时停止播放并收起播放条。待确认。
3. **视频全屏左右滑动**：建议与图片一致，全屏可左右滑动浏览其它图片/视频；音频不进全屏。待确认。
4. **音频格子内容**：建议只显示音符图标 + 播放键，不显示时长（保持简单）；如需时长再议。
5. **目录"配图"页缩略图**：视频 = 抽帧 + 播放角标；音频 = 音符图标 + 播放角标。待确认。

## 四、选择器方案（实现约定）

- 系统相册选择器只支持图片/视频，**不支持音频**；为了一次选全所有媒体，统一改走文件选择器：
  `ACTION_OPEN_DOCUMENT` + `EXTRA_MIME_TYPES=[image/*, video/*, audio/*]` + `EXTRA_ALLOW_MULTIPLE`。
- 模拟器上文件选择器长按可进入多选（已实测可用），真机 DocumentsUI 同样支持多选。
- 代价：真机上不再用系统相册选择器（勾选多图）界面；统一为文件选择器，换取一条链路选全媒体。

## 六、不变项

- 长按小悬浮窗仍叫"配图"，不加新入口。
- 多选模式、全选、目录页长按菜单（保存/保存所有/删除所选）逻辑不变。
- 独占一页、显示高度、换页/缩放规则对媒体格同样生效。
- 版本规则与测试约束不变：只编 appC、只测雷电模拟器、每改一版提交一次、按编译文档递增版本。
