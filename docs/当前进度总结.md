## 技术架构

### 当前架构

```
音频书：
BookTocLoadingActivity 
  → ReadBookActivity
     → ContentProcessor（显示占位文本）
     → （待实现）BaseReadAloudService + SourceAudioEngine 播放

普通书：
BookTocLoadingActivity
  → ReadBookActivity  
     → ContentProcessor（显示正文）
     → BaseReadAloudService + TTSReadAloudService 朗读
```

### 目标架构（第一阶段完成后）

```
所有书籍：
BookTocLoadingActivity
  → ReadBookActivity
     → ContentProcessor（音频书显示字幕/占位，普通书显示正文）
     → BaseReadAloudService
        ├─ SourceAudioEngine（音频书）
        ├─ SystemTtsEngine（普通书）
        └─ HttpTtsEngine（普通书）
```
